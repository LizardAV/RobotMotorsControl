# RobotMotorsControl
Проект для управления двигателями робота

## Описание проекта
Проект представляет собой систему управления двигателями робота на Питоне. Это мой первый проект в такой истории:) Не могу не признаться, в коде Питона я чуть воспользовался помощью нейронки, но только чуть-чуть. Самое главное, что как мне кажется - с заданием я справился


## Работа с Git

### Создание и клонирование репозитория

Репозиторий был создан через веб-интерфейс.
Клонирование было выполнено через bash
git clone https://github.com/LizardAV/RobotMotorsControl.git

### Процесс сохранения изменений
Сохранял с помощью команд:
git add .                # Добавление всех изменений
git commit -m "описание" # Фиксация изменений
git push origin ветка    # Отправка на сервер

### Взаимодействия с ветками
Была создана ветка feature/smooth-control для новых функций:
git checkout -b feature/smooth-control

### Пул-реквесты
Был создан пул-реквест "Add smooth speed control and user interface". Он содержал реализацию плавного изменения скорости, добавления интерактивного интерфейса пользователя, а также улучшение обработки ошибок.

### Основные изменения в коде
Добавление функций:
1. Плавное изменение скорости - функция smooth_speed_change позволяет менять скорость постепенно.
2. Интерактивный интерфейс - метод handle_user_input предоставляет меню управления.
3. Обработка ошибок - добавлена проверка входных данных и состояние системы.
